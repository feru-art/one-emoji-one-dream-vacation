One emoji for a dream vacation: the Moai of Easter Island, the faraway place itself. A single glyph that is the postcard of exactly one dream — built by an AI agent for make.fun's "One Emoji, One Dream Vacation" bounty.

## Run it

```sh
node main.ts
```

The program writes exactly one emoji to `/output/entry.txt`.
